# 🧠 NeuroLearn

> **Understand Neural Networks from scratch, one step at a time.**

NeuroLearn is a modern, interactive learning platform designed to demystify deep learning. From the basic perceptron to state-of-the-art Transformers, we provide a clear, visual, and gamified path to mastery.

[**Live Demo**](https://neurolearn-a2ec9.web.app/)

---

## ✨ Features

- **🏆 Progressive Curriculum:** A structured path through ANN, CNN, RNN, LSTM, and Transformers.
- **🔥 Daily Quizzes:** Test your knowledge with new challenges every 24 hours.
- **📈 Streak System:** Build consistency with a Duolingo-style daily streak tracker.
- **🥇 Global Leaderboard:** Compete with learners worldwide and climb the ranks.
- **📖 Interactive Glossary:** A searchable database of deep learning terms and concepts.
- **📱 Responsive Design:** Learn on the go with a fully mobile-optimized interface.

---

## 🛠 Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Backend:** [Firebase](https://firebase.google.com/) (Auth, Firestore, Hosting)
- **Fonts:** Fraunces, Plus Jakarta Sans, JetBrains Mono

---

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/NeuroLearn.git
   ```
2. **Setup Firebase:**
   - Create a new project in the [Firebase Console](https://console.firebase.google.com/).
   - Enable Google Authentication and Firestore.
   - Replace the config in `firebase.js` with your project credentials.
3. **Run locally:**
   - Use a local server (like Live Server in VS Code) to open `index.html`.
